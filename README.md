# data/ — Parking video feeds & ROI location files

Put your input files in this folder:

| File | Purpose |
|------|---------|
| `parking_lot.mp4` | The parking-lot CCTV video you download (PKLot / Kaggle). |
| `rois.json` | Parking-slot ROI coordinates. Generated by `classical_detector/slot_picker.py`. |
| `output/` | Annotated output videos saved by the detectors. |

## Download a sample video

1. PKLot Parking Lot Image & Video Dataset (Kaggle):
   https://www.kaggle.com/datasets/istech11/parking-lot-image-and-video-dataset

2. Parking Lot Occupancy Detection Video Streams (Kaggle / Roboflow):
   https://www.kaggle.com/datasets/ammarnassanalhajali/parking-lot-occupancy-detection

## Create your ROI file

```bash
python classical_detector/slot_picker.py data/parking_lot.mp4 --output data/rois.json
```

Left-click corners, press `n` per slot, `q` to save.
